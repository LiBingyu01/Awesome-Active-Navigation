# Contributing to Awesome Active Navigation

Please open an issue/PR with: exact official paper title; author or publisher paper URL; publication venue/status and year; platform (ground/aerial); goal type; observation/action space; three evidence-grounded takeaways; and a relevance label (Core, Adjacent, Baseline, Benchmark).

Avoid duplicate titles. Do not present arXiv preprints as formally accepted publications. A navigation paper need not be Active Navigation: justify the information-seeking component.

## 提交格式

请附：真实论文标题、论文原始链接、发表状态、平台、本体观察与动作设定、三点技术简评以及是否真正涉及主动信息获取。不要将普通 VLN 自动标注为 Active Navigation。

## Special Track: Code Agents for Navigation

Use `Code-Nav` for actual executable program generation in navigation; `Code-Transfer` for code synthesis on other embodied tasks; `Tool-Agent` for tool-calling systems without demonstrated new code synthesis. Do not claim active object discovery from ordinary navigation demonstrations.

中文：新增代码智能体条目时，务必核验是否真的生成**可执行导航代码**，还是仅调用预定义工具；明确区分导航实验与操作/虚拟探索的关联工作。
